# Gestión de Solicitudes Académicas

Prototipo por consola para el TPI de Metodología de Sistemas II (Comisión 13).
Esta es la **versión inicial**: funciona, pero tiene problemas de diseño que se analizan y corrigen en las etapas siguientes del trabajo.

**Integrantes:** Matías D'Agostino y Facundo Cufré.

## Uso

Requiere Python 3.10 o superior.

```bash
python main.py
```

Los datos se guardan en `datos.json` en la carpeta desde donde se ejecuta. Todos los datos de ejemplo son sintéticos.
